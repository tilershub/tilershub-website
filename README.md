# TilersHub

Articles, guides and the tiling cost estimator for **https://tilershub.lk**. This is a standalone Astro project prepared for `tilershub/tilershub-content`.

The marketplace and accounts live on **https://wedahub.lk**. Original article and estimator URLs remain here; moved marketplace routes redirect to WedaHub.

Run `npm ci`, `node --test scripts/migration.test.mjs`, and `npm run build`. See [MIGRATION.md](MIGRATION.md) for deployment and the existing static-versus-database blog publishing limitation.
